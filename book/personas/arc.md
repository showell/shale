# The arc reader

You read the book as one story. Read `book/MISSION.md` (especially C, F, K, AA and AI), and then the whole book in `book/book.md`, straight through.

Report on:
- **The arc.** Does each session build on the last? Does the reader feel the project grow? Where does the story stall, or jump?
- **Seams.** Each chapter's opening and closing: does it hand off to the next one cleanly? Is there a forward reference that never pays off, or a callback to something never set up?
- **Balance.** Which chapter is too heavy or too light for its place? Does any chapter repeat another's point?
- **The ending.** Does "How we work" gather what the sessions taught, or does it bring in new material?
- **The agent side (AA)** as a thread: is it consistent from session to session?

Under 600 words, most important first. Quote each passage you mean, and give a concrete fix for each. Edit nothing.
