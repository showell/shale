# c/builtins.txt: Shale's builtins, every one, typed: the one home of the
# builtin surface (c/docs/builtin-table.md). c/check_builtins.shale holds the
# C (c/script/ast.h, c/script/vm.c), the preludes (c/preludes/*.shale) and
# the docs to it in the fast tier, and c/gen_builtins.shale writes the Roc
# platform's surface from it (roc_platform/platform/Shale.roc, main.roc and
# roc_platform/host/hosted.gen.c).
#
# A builtin is a stanza, blank lines between: its signature on a line of its
# own, from the line's start, then `key: value` lines indented two spaces.
# A `#` line is a comment.
#
#   name(arg: Type, arg?: Type, rest...: Type) -> Type
#
# An argument with `?` may be left out (and those after it); `...` takes any
# number. The types are Shale's values, named for what they hold: Str, Int,
# Bool, Nil, Any, Path (a Shale path: the root's, or `mount:rest`), List(T),
# Map (string keys), Map(T), Table (a list or a map), Scalar, Opts (a map of
# options, keyed as `opts:` says), `{field: T, ...}` (a map of those fields),
# `A | B` (either), Never (the call does not return), and a record named
# for its builtin's docs (Entry, Match, RunResult, Job, Hit, Decl, Token,
# Tree, HttpResponse, MoveReport, JobEnd, Proc, Import, Edit).
#
# The keys:
#   impl:    where it is: `c <function>` (vm.c's builtin_specs()), `vm OP_PRINT`
#            (the VM's own op), or `prelude core|linux|git` (c/preludes/).
#   kind:    `effect` (it reaches outside its arguments: the store, programs,
#            the clock, the run's output, arguments and budgets, or it stops the
#            run), `pure` (its answer is its arguments' alone: Roc does these
#            itself), or `internal` (a prelude's helper, no part of the surface;
#            its name is taken all the same).
#   stops:   the classes it stops with, beyond a wrong type (`type`) or count
#            of arguments (`argument`), which every builtin has.
#   opts:    an Opts argument's keys and their types.
#   doc:     one line: what it gives.
#   anchor:  where its docs are, `file#heading`; that section names it.
#
# An effect exported to Roc (only effects are: Roc does pure work itself)
# says how, in five more keys:
#   roc:        its declaration in Shale.roc, `name! : Arg, ... => Answer`;
#   roc_params: each argument's name, the request's fields in the driver;
#   roc_doc:    its doc comment in Shale.roc;
#   values:     the outcomes that are values (a `Missing`, an exit code):
#               every other outcome, a refusal or a budget, is a stop;
#   driver:     the driver's Shale for it, a line a key: `q` is the request,
#               and what it returns is the answer, a tag union's as
#               `{tag = "Name", value = payload}`.

ls(p: Path) -> List(Str)
  impl: c builtin_ls
  kind: effect
  stops: file_system
  doc: a folder's names, sorted
  anchor: docs/SHALE.md#the-store
  roc: list! : Str => [Found(List(Str)), Missing]
  roc_params: path
  roc_doc: A folder's names, sorted, or `Missing` when nothing is at the path (Shale's `ls`).
  values: Found(names); Missing, when nothing is at the path
  driver: if not exists(q.path) then return {tag = "Missing"} end
  driver: return {tag = "Found", value = ls(q.path)}
