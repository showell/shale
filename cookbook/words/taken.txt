-- read as the word's own meaning, not the author's. The Roc name hunt's
-- `taken_word` reads them, a word and its kind a line:
--   roc       Roc's own word for a kind of type or a file: a function

--             Roc"). A function that gives that very thing (`record :
--             ApiKey.Key -> ApiKey.Record`) is honest, and passes.
--   cardinal  a number's name: a value named `two` says how many, not what
--             it holds (`three : List(Fields)`). A function so named
--             (`Time.two : I64 -> Str`, a two-digit field) is no count.
-- `--` starts a note.
