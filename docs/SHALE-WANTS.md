# What Claude reached past Shale for

The ledger the dogfood design names (`docs/designs/DESIGN-shale-dogfood.md`,
"Making the ban real"). The ban is in force: the gate (`tools/shale_gate.zig`,
SHALE-AGENTS.md's "The gate") passes only a `shale` launch or a logged
escape. Each escape is a line in `~/.local/state/shale/wants.tsv`, and this
file gathers them: a line is the date, a tag, what was done, and the Shale
that would do it; a tag that recurs three times goes to the queue.
